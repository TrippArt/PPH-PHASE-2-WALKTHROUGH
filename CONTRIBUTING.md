# Contributing: Tripp Art LLC team setup

This repo is public, so anyone can view it and the live walkthrough. To **change** it you need your own GitHub account, an invite from Tripp, and (if you want an AI to do the editing) ChatGPT connected to GitHub. Every change goes in as a pull request that Tripp approves; nothing goes live until he merges it.

## One-time setup (each team member)

1. **GitHub account.** Sign up at https://github.com/signup (free). Send Tripp your **GitHub username**.
2. **Accept the invite.** Tripp adds you as a collaborator. Accept it from the email GitHub sends, or at https://github.com/TrippArt/PPH-PHASE-2-WALKTHROUGH/invitations.
3. **Connect ChatGPT to GitHub** (needs a paid ChatGPT plan that includes Codex):
   - Go to https://chatgpt.com/codex and choose to connect GitHub. Sign in as yourself and authorize the "ChatGPT Codex Connector".
   - Create an environment and pick the repository **TrippArt/PPH-PHASE-2-WALKTHROUGH**.
   - If the repo is not in the list, the Codex Connector app is not yet allowed on Tripp's account for this repo. Ask Tripp (see "Tripp's one-time steps" below), or use the fork route at the bottom of this page.

## Making a change with ChatGPT (Codex)

1. In Codex, select this repo and describe the change in plain words, for example: "On the M7 Viper wall, move the door label up 1 ft."
2. Codex reads `AGENTS.md` (the rule book) and makes the change in its own sandbox. Read its summary and the diff.
3. Click **Create PR**. Fill in the checklist if Codex didn't.
4. Tell Tripp (or the team channel) the PR link. He reviews and merges, and the live site updates about a minute later.

**Without an AI:** open the repo on github.com, press `.` to open the web editor, make the edit, then commit to a **new branch** and open a pull request.

## Rules that matter most

The full list is in `AGENTS.md`. The short version:

- `index.html` holds every measurement. Don't change a number unless Tripp gave it to you, and say so in the PR.
- Never hand-edit `pph-zone3-spec.json` or anything in `layers/`. They are generated by `tools/make_spec.py` and `tools/make_layers.py`.
- Don't rename walls. **B4 = the B4 Mirror Band** (above the mirrors right of M4). **B5 = the band on the box face over M6.** Wall 4 sections are the M4 size: Section 1 = M4, Sections 2 to 4 = B4-1, B4-2, B4-3.
- Never touch the M4 mural. Wall 1 stays blank.
- Never push straight to `main`. Always use a pull request.

## Tripp's one-time steps

- **Invite each person:** repo Settings → Collaborators → Add people, with the **Write** role (or ask Claude Code on QUEEN to do it with their usernames).
- **Allow Codex on this repo:** connect your own Codex to GitHub once at https://chatgpt.com/codex. When GitHub asks where to install the ChatGPT Codex Connector, choose the **TrippArt** account and "Only select repositories" → this repo. That install is what lets the team's Codex see it.
- **Optional:** turn on branch protection for `main` (Settings → Branches) so every change needs a pull request.

## Fork route (if Codex can't see the repo)

1. On the repo page click **Fork** to make your own copy.
2. Connect Codex to **your fork**, make the change there, and let Codex create the PR in your fork.
3. On GitHub, open your fork and click **Contribute → Open pull request** to send the change to TrippArt/PPH-PHASE-2-WALKTHROUGH.
